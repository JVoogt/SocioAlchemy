# SocioAlchemy Website Plan

## Overview
Single-page static website for socioalchemy.co.za. Modern, on-brand, fast-loading. Hosted via Docker (nginx) on DockPi with Traefik routing.

## Technology
- Pure HTML5 + CSS3 + minimal vanilla JS (smooth scroll, mobile menu, lazy loading)
- No frameworks, no build tools — pure static files served by nginx
- Responsive (mobile-first design)
- Optimized images from existing media assets
